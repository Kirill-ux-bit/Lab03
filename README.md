# Лабораторная работа №3
## 1. Представлени числа в байтах
 1) Число 1 занимает 4 байта потому, что указан int, который занимает дополнительный байты.
 2) В байтовом представлении числа 256 не меняется само значение, но требуется больше одного файла на хранение.
 3) Число 65536 требует другого набора байтов потому, что с увеличением числа требуется другой набор.
## 2. Порядок байтов
 1) BitConverter.IsLittleEndian - указывает на прядок байтов в архитектуре компьютера.
 2) В hex: 0x12345678
 3) Байты числа: 78-56-34-12
 4) Порядок записи байтов числа 305419896 в последовательность 78-56-34-12 связан с архитектурой процессора и используемым порядком байтов.
## 3.Текст и UTF-8
 1) Количество символов и байтов различается потому, что слова написаны на разных языках, имеют разное значение и отличаются по количеству символов.

ABC:
Количество символов: 3
Количество байтов UTF-8: 3

Привет:
Количество символов: 6
Количество байтов UTF-8: 12
## 4. Английская и русская буква

 Русская А: D0-90
  
 Различие заключается в том что буквы из разных алфавитов являются разными символами.
 ## 5. Обратное преобразование
 Для обратного преобразования нужно указывать UTF-8 чтобы программа понимала как именно читать байты, чтобы собрать исходное слово.
## Контрольные вопросы
 1) Байт — единица хранения данных. 1 байт = 8 бит

2) Тип int занимает несколько байтов, потому что должен хранить не один бит, а целое число в определённом диапазоне. В C# int занимает 4 байта.

3) BitConverter.GetBytes() преобразует значение примитивного типа, например int, в массив байтов (byte[]) — его двоичное представление в памяти.

4) BBitConverter.IsLittleEndian - указывает на прядок байтов в архитектуре компьютера.

5) Числа обычно записывают слева направо от старшего разряда к младшему. В памяти же порядок байтов зависит от соглашения платформы: например, в little-endian младший байт хранится первым.

6) Количество символов строки не всегда равно количеству байтов, потому что символы кодируются по-разному. Например, в UTF-8 некоторые символы занимают один байт, а некоторые — несколько.

7) Encoding.UTF8.GetBytes() кодирует текст в UTF-8 и возвращает его байтовое представление в виде byte[].

8) Для обратного преобразования используют Encoding.UTF8.GetString(): он декодирует байты, закодированные в UTF-8, обратно в строку.

9) Одни и те же байты могут интерпретироваться по-разному в зависимости от типа данных и кодировки. Например, набор байтов может означать число, текстовый символ или часть другого формата данных.

10) Число хранится как двоичное значение фиксированного размера, а текст — как последовательность байтов, полученная с помощью кодировки. Поэтому для восстановления текста нужно знать, какая кодировка использовалась.
## Итоговый вывод
 Одной последовательности байтов знать недостаточно. Нужно знать правила кодировки потому, что без них те же байты могут обозначать другие данные.
